What does this prove?

Encryption hides a message. A recipient’s public key encrypts; their private key decrypts. Signing does not hide it. A signer’s private key creates a signature; their public key verifies it. This demo uses RSA-PSS with SHA-256, not “encryption with a private key.”

A valid signature is not proof of real identity. It links the exact text and drawing to a key. Anyone can create keys and claim a name. This teacher login controls who may use the demo; it is not a certificate or trusted identity check for the disposable public key. No official or legally verified signature is created.

RSA-2048 is a conventional educational baseline balancing computation and security, not a guarantee for every long-term use. The drawing coordinates and text are encoded in a fixed JSON format and signed together. Use only fictional data. Leaving this section, refreshing, or detected sign-out clears the working copy.
