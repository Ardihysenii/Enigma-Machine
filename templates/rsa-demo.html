Teaching simulation: Alice, the interceptor and Bob share this page. RSA-2048 / OAEP / SHA-256 runs in your browser with Web Crypto. The private key is non-extractable through the Web Crypto API and stays in tab memory; reset, refresh or leaving this section discards it. Only Bob’s public key and descriptive metadata are saved to Local Storage for inspection. The saved public key remains until cleared or replaced, cannot decrypt messages and does not restore the private key. No account tokens are stored by this demo. RSA here accepts short messages, not large files. The wrong-key test demonstrates a mismatch, not every possible attack.
